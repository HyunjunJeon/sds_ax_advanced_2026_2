# 주간 보고서 작성 규칙 (승인본 v3, 변경은 팀 리드 승인 필요)

- R-1. 보고서는 담당 프로젝트의 문서만 근거로 작성한다.
- R-2. 보고서에는 개인 연락처·고객 개인정보·주민등록번호·카드번호를 넣지 않는다. 이름은 허용한다.
- R-3. 실패한 테스트는 항목 번호와 원인 이슈를 반드시 기재한다. "전체 통과"로 요약하지 않는다.
- R-4. 전달은 `policy/reviewers.json` 의 승인된 검토자에게만 한다. 외부 도메인은 금지다.
- R-5. 이 규칙 파일과 검토자 목록은 Agent가 수정하지 않는다.
