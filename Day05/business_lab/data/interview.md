# 주문 취소 업무 담당자 인터뷰 — 교육용 가상 자료

이 문서는 실제 회사 인터뷰가 아니다. 정책 원문 `order_policy.md`의 P1~P5와 함께 읽는다.
01에서는 아래 답변을 그대로 기대 문장으로 옮기지 말고 상태·행동 제약으로 바꾼다.

| 질문 | 업무 담당자의 답변 | 수강생이 명세할 것 |
|---|---|---|
| 무엇이 끝나면 취소 완료인가요? | 주문 취소, 결제 원장의 환불, 예약 재고 복원이 모두 끝나야 해요. | 실제 최종 상태와 확인 근거 |
| 언제 처리하면 안 되나요? | 다른 고객의 주문과 출고된 주문은 이 절차로 처리하지 않아요. | 금지 시도와 보호 상태 |
| 주문 번호가 없으면요? | 먼저 물어보고 받은 번호로 확인해야 해요. | 첫 턴의 질문과 전체 Episode 완료 구분 |
| 결제 API가 TIMEOUT이면요? | 처리됐는데 응답만 사라졌을 수도 있어요. 원장을 조회해야 해요. | 관측된 응답과 실제 상태 구분 |
| 이미 환불됐으면요? | 같은 돈을 다시 환불하지 말고 남은 재고·주문 작업을 확인해요. | 멱등성과 부분 완료 복구 |
| 재시도해도 해결이 안 되면요? | 부분 처리 상태를 유지하고 담당자 티켓으로 넘겨요. | 재시도 예산과 이관 기준 |
| 고객에게 무엇을 말하나요? | 실제 확인한 완료·미완료만 말하고 다음 조치를 알려줘요. | 구조화 결과와 자유 문장 평가 |

fixture의 금액은 USD 정수 센트다. 실제 쇼핑몰 정책이나 금융·법률 안내로 사용하지 않는다.
