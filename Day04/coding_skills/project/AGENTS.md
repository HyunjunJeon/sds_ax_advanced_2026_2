# 이 작업 폴더의 개발 규칙

- 이 폴더의 Python 프로그램과 테스트만 작업한다. 먼저 README의 계약과 실행 명령을 읽는다.
- Python 표준 라이브러리를 사용한다. 패키지 설치, 외부 API 호출, Git 커밋은 이 실습에 필요 없다.
- 기존 테스트를 삭제하거나 skip/xfail로 바꾸지 않는다. 기대값을 구현에 하드코딩하지 않는다.
- 기존 `tests/test_report.py`는 보존한다. 추가 반례는 새 테스트 파일에 작성한다.
- 명시적으로 코드 리뷰만 요청한 경우 소스·테스트·README를 수정하지 않는다.
- 결과 보고에는 수정 파일, 실제 실행 명령·종료 코드, 남은 한계를 적는다.
- `/skills/`는 읽을 Skill, `/artifacts/`는 이번 실행의 보고서 저장 위치다.
- 파일 도구의 `/`는 이 프로젝트 폴더다. `execute`의 현재 디렉터리도 이 프로젝트 폴더다.
- `python`은 실행기가 연결한 Day04 Python이다. 테스트는 `python -m unittest discover -s tests -v`로 실행한다.
