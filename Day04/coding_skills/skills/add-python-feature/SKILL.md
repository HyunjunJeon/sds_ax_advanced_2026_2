# 기존 계약을 보존하며 기능 추가하기

1. README·진입점·관련 함수·테스트를 읽는다. 요청한 입력·출력과 기존 기본 동작을 구분한다.
2. 결과를 바꿀 중요한 조건이 빠졌으면 사용자에게 확인한다. 이미 받은 조건은 다시 묻지 않는다.
3. 새 테스트 파일에 새 기능의 성공 사례와 경계 사례를 작성한다.
   기능을 추가하기 전에 새 테스트가 실제로 실패하는지 실행한다.
4. 프로젝트의 기존 구조와 의존성을 사용해 기능을 구현한다. 요청한 옵션명과 출력 형식을 유지한다.
5. 기존 테스트와 새 테스트를 실행하고 CLI도 직접 호출한다. 기능을 사용하지 않은 호출의 동작도 확인한다.
6. 사용법을 README에 반영하고 `show_diff`를 확인한다.
7. `/artifacts/feature-report.md`에 요구사항·변경 파일·실행 명령과 결과·확인하지 못한 내용을 기록한다.
   실제 테스트를 실행하지 않았다면 완료로 보고하지 않는다.
