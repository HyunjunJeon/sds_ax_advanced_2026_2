# 관련된 경계만 골라 추가 반례 만들기

| 코드의 조건 | 확인할 반례 |
|---|---|
| 날짜 범위 | 시작일 당일, 종료일 당일, 시작일과 종료일이 같은 하루, 범위 바로 밖 |
| 금액 합계 | 소수 금액, 음수 환불, 합계 0, 여러 고객 |
| CSV 입력 | 데이터 행 없음, 행 순서 변경, 같은 고객의 여러 행 |
| 상태 필터 | 포함 상태와 제외 상태가 같은 기간에 섞임 |

계약이 정하지 않은 동작은 먼저 확인한다. 특정 샘플의 숫자를 일반 규칙으로 사용하지 않는다.
기존에 없는 경계 사례 하나를 고르고, 왜 이 입력이 같은 종류의 결함을 잡는지 설명한다.
