# 실패를 재현하고 Python 코드 고치기

1. 프로젝트 README와 관련 소스·테스트를 읽어 기대 동작을 확인한다.
2. `execute`로 실제 실패를 먼저 재현한다. 실행 명령과 종료 코드를 확인한다.
   재현하지 못하면 그 사실을 남기고 입력·실행 환경을 확인한다.
3. 실패 입력이 어떤 분기를 통과하는지 추적하고 원인을 좁힌다.
   기존 동작을 보존하는 최소 수정을 한다. 기대값을 바꾸거나 특정 입력을 특별 취급해 통과시키지 않는다.
4. 새 테스트 파일에 추가 반례를 작성한다. 날짜·금액·CSV 경계가 관련되면
   [경계 사례 참고 자료](references/boundaries.md)에서 해당 항목만 참고한다.
5. 관련 테스트와 프로젝트의 기존 테스트를 실제 실행한다. 실패하면 로그를 읽어 수정한다.
   같은 실패가 계속되면 확인한 원인과 막힌 지점을 보고한다.
6. `show_diff`로 변경 범위를 확인하고 `/artifacts/fix-report.md`에
   원인·수정 파일·재현 명령·최종 검사 결과·남은 한계를 기록한다.
7. 최종 답변에는 실제 변경과 실행 결과, 보고서 경로를 남긴다.
