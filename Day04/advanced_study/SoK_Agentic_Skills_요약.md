# SoK: Agentic Skills 요약

Yanna Jiang, Delong Li, Haiyu Deng, Baihe Ma, Xu Wang, Qin Wang, Guangsheng Yu.
University of Technology Sydney · CSIRO Data61.
arXiv:2602.20867v1, 2026-02-24.
원문: [SoK_Agentic_Skills_2602.20867.pdf](SoK_Agentic_Skills_2602.20867.pdf)

에이전트는 과제가 바뀔 때마다 실행 전략을 처음부터 다시 짠다. 이 논문은 그 빈칸을 **agentic skill**로 둔다. Skill은 재사용·호출 가능한 모듈로, 적용 조건, 실행 정책, 종료 조건, 인터페이스를 한 덩어리로 담는다. 한 번 쓰는 계획이나 원자적 도구 호출과 달리, 과제 사이를 가로지른다.

문헌 검색에서 약 180편을 보고 65편을 남겼다. 그중 24개 시스템을 표로 깊게 본다.

## 정의

\[
S = (C, \pi, T, R)
\]

| 기호 | 역할 |
|---|---|
| \(C\) | 적용 조건. 지금 관측·목표가 이 Skill의 대상인지 |
| \(\pi\) | 실행 정책. 관측·이력을 행동 또는 다른 Skill 호출로 보냄. 자연어, 코드, 학습된 제어기, 혼합 가능 |
| \(T\) | 종료 조건. 성공·실패를 포함해 언제 끝나는지 |
| \(R\) | 호출 인터페이스. 이름, 인자, 반환 |

\(C\)가 없으면 스스로 고르지 못하고, \(T\)가 없으면 조합할 수 없으며, \(R\)이 없으면 프로그램으로 부를 수 없고, \(\pi\)가 없으면 실행할 것이 없다. RL의 option \((I,\pi,\beta)\)와 대응하되, \(R\) 때문에 런타임에 명시적으로 호출된다.

도구는 한 번의 API, 계획은 세션 안의 분해, 일화 기억은 「무엇이 있었는지」, 프롬프트 템플릿은 조건·종료·인터페이스가 없는 텍스트다. Skill은 절차 기억이다. 「무엇을 아는가」가 아니라 「어떻게 하는가」다.

SkillsBench를 인용한다. 사람이 고른 Skill은 통과율을 평균 +16.2 포인트 올리고, 모델이 혼자 쓴 Skill은 −1.3 포인트다. 작은 모델 + 고른 Skill이, Skill 없는 큰 모델을 이길 수 있다.

## 수명주기

발견 → 연습/정제 → 증류 → 저장 → 검색/조합 → 실행 → 평가/갱신. 직선이 아니다. 평가가 연습으로, 실행 실패가 발견으로 돌아간다.

## 일곱 패턴

시스템 수준 패턴이다. 배타적이지 않다. 실제 시스템은 중앙값 2개를 겹쳐 쓴다.

| # | 패턴 | 요지 | 주된 위험 |
|---|---|---|---|
| 1 | Metadata-driven disclosure | 설명만 올려 두고, 고르면 본문을 읽는다 | 메타데이터 오염 |
| 2 | Code-as-skill | 실행 스크립트 | 코드 인젝션 |
| 3 | Workflow enforcement | 순서를 강제 (예: 테스트 먼저) | 규칙 우회 |
| 4 | Self-evolving library | 실행 후 라이브러리를 스스로 고친다 | Skill drift, 독성 증류 |
| 5 | Hybrid NL+code | 지침과 코드가 한 패키지 | 지침과 코드가 다를 때 |
| 6 | Meta-skill | Skill을 만드는 Skill | 오류가 재귀로 증폭 |
| 7 | Marketplace | 버전 있는 패키지로 배포 | 공급망 (ClawHavoc) |

표현(자연어 / 코드 / 도구 매크로 / 정책 / 혼합)과 범위(단일 도구, 웹, OS, SWE, 로봇 등)는 이와 직교하는 축이다. SkillsBench에서 이득은 의료 +51.9, 제조 +41.9, 소프트웨어 공학 +4.5, 수학 +6.0으로 갈린다. 사전학습에 절차가 부족한 영역에서 Skill 값이 크다.

## 보안

위협 여섯: 검색 중독, 악의 페이로드, 테넌트 간 누출, Skill drift, confused deputy(환경 주입), 적용 조건 오염.

신뢰 티어: T1 메타데이터만, T2 지침, T3 감독 실행, T4 자율 실행. 티어 전환은 런타임이 강제해야 한다. Skill이 스스로 승격하면 안 된다.

사례 **ClawHavoc**: OpenClaw의 ClawHub에 악의 Skill이 약 1,200개 들어갔다. 한 분석은 공개 Skill의 36.8%가 보안 결함을 가졌다고 본다. 페이로드는 API 키, 암호화폐 지갑, 브라우저 자격 증명, SSH 키를 가져갔다. 악성 Skill의 91%에 프롬프트 인젝션이 포함됐다.

## 평가에서 남는 말

결정적 검증기가 있는 환경이 재현에 유리하다. 사람이 고른 Skill과 모델이 쓴 Skill의 차이가 반복된다. 자기 생성은 실행 검증이 있는 좁은 환경(Voyager 등)에서는 되고, 열린 과제에서는 점수를 떨어뜨릴 수 있다.
